# Website image sources

`meadow-list.webp` and `sunroom-focus.webp` are captures of the actual Three Things 0.10.0 packaged Mac app, using an isolated temporary data directory and synthetic example priorities. They are not photos of a user's desktop. The application and saved user data were not edited to produce them.

Photographs visible inside the app:

- **Meadow:** https://unsplash.com/photos/d5ChyDj4Mwk — source and license verification recorded in `assets/photo-sources-v6.json`.
- **Sunroom:** MAHDI HAJIZADE, https://unsplash.com/photos/the-sunlight-is-shining-through-a-window-in-a-building-cF71DVQjR4o — source recorded in `assets/PHOTO-CREDITS-v5.md`.

Both photographs are already bundled with the app under the [Unsplash License](https://unsplash.com/license). The website screenshots are stored locally as optimized WebP images; no third-party image request is needed to view the page.

Existing `focus.webp` and other release imagery remain available for existing links.
